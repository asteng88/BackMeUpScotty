# Support

## Before opening an issue

- Read the [README](README.md) and confirm that you are using a current build.
- Check existing issues for the same question or behavior.
- For a suspected security issue, follow [SECURITY.md](SECURITY.md) instead of
  opening a public issue.

## Getting help

Use a GitHub issue for reproducible bugs or well-scoped feature requests.
Include your Windows version, app version or commit, the action you took, and
the full error text or screenshots when relevant. Never include private folder
names, backup contents, passwords, or other sensitive information.
