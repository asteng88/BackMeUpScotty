# Security Policy

## Supported versions

Security fixes are made on the latest version in the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead,
contact the repository owner privately with a description, reproduction steps,
and any suggested mitigation. You should receive an acknowledgement within
seven days.

Because this application reads from and writes to user-selected folders,
reports involving path handling, unintended overwrite, privilege boundaries,
or data loss are especially valuable.
