# Bundled Retro Fonts

BackMeUpScotty registers these files privately for its own process on Windows;
they are not installed system-wide.

| File | Used for | Source and license |
| --- | --- | --- |
| `Speccy.ttf` | ZX Spectrum interface | Kreative Software, Free Use License 1.2f |
| `PetMe64.ttf` | Commodore 64 interface | Kreative Software, Free Use License 1.2f |

The license notice is included verbatim beside the relevant font files.
The fonts and notices were sourced from the Faerie project’s bundled-font
collection: <https://github.com/KiwiGeek/Faerie/tree/master/src/Faerie.Terminal.Avalonia/Assets/Fonts>.
