# Code of Conduct

## Our standards

Everyone participating in this project is expected to be respectful,
constructive, and welcoming. We do not tolerate harassment, discrimination,
personal attacks, or publication of another person's private information.

When reviewing or discussing work, focus on the code and its impact rather
than on the contributor. Assume good intent, ask clarifying questions, and
make space for different experience levels.

## Scope

This policy applies in project issues, pull requests, discussions, and other
project spaces, as well as when someone is representing the project publicly.

## Enforcement

Report unacceptable behavior privately to the repository owner. Reports will
be handled confidentially and reviewed fairly. Responses may include a request
to correct behavior, removal of content, a temporary ban, or a permanent ban.
